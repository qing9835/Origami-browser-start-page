# 折纸起始页

一个安静、极简的个人浏览器起始页 / 新标签页。纯前端单文件，双击 `index.html` 即可使用，无需后端。

> 「在朦胧光影中，让每一次搜索与跳转，都成为一场极简的日常仪式。」

## 预览

![折纸起始页](assets/screenshot.jpg)

## 特性

- 🔍 **多搜索引擎**：百度 / 必应 / 谷歌 / Yandex / 搜狗 / 360，`Alt+1~6` 秒切，支持自定义引擎
- 💬 **搜索联想**：跟随当前引擎实时补全，`↑↓ / Enter / Esc` 键盘操控
- 🖼️ **动态壁纸**：内置多张高清壁纸，可上传本地图片自动压缩为自定义壁纸
- 🧭 **底部快捷导航**：站点可增删、排序、单独隐藏
- 🌓 **外观可调**：浅/深主题、背景亮度、搜索框透明度
- 💾 **配置本地记忆**：所有设置存于浏览器 `localStorage`

## 使用

双击 `index.html` 打开即可；联网时可用搜索联想。

- **快捷键**：`/` 聚焦搜索框，`Esc` 清空/关闭，`Alt+1~6` 切换搜索引擎
- 右上角齿轮打开**设置面板**（显示 / 搜索引擎 / 壁纸 / 底部导航）

## 目录结构

```
├── index.html          起始页（结构 + 样式 + 脚本 全在此）
├── translate.html      翻译页（Google 免费 / AI / 腾讯 TMT）
├── assets/             静态资源（图片 + 图标）
│   ├── lucide.min.js     Lucide 图标库（自托管）
│   ├── favicon.svg       站点图标
│   ├── screenshot.jpg    效果预览图
│   └── wallpapaer/       壁纸（完整背景 + 缩略图）
└── README.md           本文档
```

## 说明

- **技术栈**：HTML + CSS + JS；Tailwind / Font Awesome 走 CDN，Lucide 自托管，Google Fonts。
- 自定义壁纸、搜索引擎、底部导航保存在各自浏览器的 `localStorage`，互不影响。
- 搜索联想依赖各引擎接口，不同网络下个别引擎可能无联想（属外部限制，不影响搜索）。
